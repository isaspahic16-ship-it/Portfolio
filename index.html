    How I work

    Four steps, the same shape every time, so you always know what comes next.

    1. 01 DiscoverWe talk through the problem, the people involved and what success looks like. It gets written down on one page before any screens exist.
    2. 02 SketchPaper and low-fidelity flows first. Three directions, then one picked together, not handed down.
    3. 03 BuildWorking prototypes in code early, so motion, timing and layout get tested on real screens instead of static mockups.
    4. 04 LaunchShip, measure, and fix what the first real users trip on. Handoff notes and a short guide come with the project.
